# 🌐 Nawfil Faraaz — Portfolio

My personal portfolio website: **Data Scientist & Software Developer** based in Dubai, UAE.

An interactive, scroll-driven site with a 300-frame image-sequence animation that "scrubs" as you scroll, showcasing my experience, AI projects, certifications and resume.

---

## ✨ Sections

- **Executive profile** – who I am and what I build
- **AI Agents / Engine / Terminal console** – interactive showcase of my AI work
- **Experience & startup** – 2+ years at TechnoCIT Dubai (Software Developer & AI Engineer)
- **Key projects** and **certifications**
- **Resume viewer** – view or download my CV (PDF and ATS-friendly DOCX in `public/`)
- **Contact**

## 🛠️ Tech stack

- Vanilla **HTML, CSS & JavaScript**
- **Vite** for dev server and production build
- Canvas-based scroll frame sequence animation

## 🗂️ Project structure

```
index.html     # Page markup
style.css      # Styles
main.js        # Scroll animation, frame loading and interactions
public/        # Resume files and static assets
logo/          # Logo assets
```

## 🚀 How to run locally

```bash
git clone https://github.com/nawfil03/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

### Build for production

```bash
npm run build      # outputs to dist/
npm run preview    # preview the production build
```

The `dist/` folder can be deployed to GitHub Pages, Netlify, Vercel or any static host.
